# Procedural Generator Suite Workspace

This workspace contains the Python-based procedural generator suite, including:
- City, Dungeon, and Village generators
- REST API for programmatic access
- GUI with main menu and submenus

## Structure
- `generators/` - Generator logic modules
- `api.py` - REST API server
- `gui.py` - GUI application
- `requirements.txt` - Python dependencies

## Usage
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Start the API server:
   ```
   python api.py
   ```
3. In a new terminal, launch the GUI:
   ```
   python gui.py
   ```

You can extend this workspace with more generators, features, or export options as needed.
